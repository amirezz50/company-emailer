# إرسال إيميلات للشركات

برنامج ويب يقرأ الإيميلات من Excel ويبعت تمبلت واحد-واحد مع تحديد الصفوف.

## التشغيل المحلي

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## النشر من GitHub

1. ارفع المشروع على GitHub (Public).
2. ادخل [share.streamlit.io](https://share.streamlit.io) وسجّل بجيت هاب.
3. **Create app** → اختار المستودع وملف `app.py`.
4. اترك التطبيق Public عشان الشاشة تفتح مباشرة من أي إيميل.
